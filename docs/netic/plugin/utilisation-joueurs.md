# 5. Guide d'utilisation pour les Joueurs

Apprenez à interagir avec NeticAI sur votre serveur Minecraft.

## 💬 Comment parler à l'IA

### Trigger par défaut
Utilisez le trigger `!ia` suivi de votre message :

```
!ia Bonjour !
!ia Comment faire une pioche en diamant ?
!ia Explique-moi la redstone
!ia Quelle est la meilleure armure ?
```

### Exemples d'utilisation

#### 🎮 Gameplay et Aide
```
!ia Comment trouver des diamants rapidement ?
!ia Quelle est la meilleure stratégie pour le Nether ?
!ia Comment construire une ferme automatique ?
!ia Quels sont les enchantements les plus utiles ?
```

#### 🏗️ Construction

#### 🧩 Mécaniques avancées

#### 🎲 Conversation et Fun

## ⏰ Limites et Cooldowns

### Restrictions
- **Cooldown** : 3 secondes entre chaque message (configurable par l'admin)
- **Rate limit** : 10 requêtes par minute maximum
- **Messages partagés** : Tous les joueurs voient la même conversation

### Messages d'erreur courants
```
[Veuillez attendre avant d'envoyer un autre message]
```
→ Attendez la fin du cooldown

```
[Vous avez atteint votre limite de requêtes]
```
→ Attendez 1 minute avant de pouvoir envoyer à nouveau

## 🔄 Historique de conversation

### Fonctionnement
- Les **20 derniers messages** sont gardés en mémoire
- L'IA se souvient du contexte de la conversation
- Tous les joueurs partagent le même historique

### Exemple de conversation
```
Joueur1: !ia Comment faire un enchantement ?
NETIC: Pour enchanter, vous avez besoin d'une table d'enchantement...

Joueur2: !ia Et quels livres faut-il ?
NETIC: Pour les livres, il faut une bibliothèque près de la table...

Joueur1: !ia Combien de bibliothèques pour le niveau max ?
NETIC: Pour atteindre le niveau 30 maximum, il vous faut 15 bibliothèques...
```

## 🎵 Support Audio (si activé)

Si votre serveur a activé le support audio, vous pouvez :

### Transcription audio
- Envoyez des fichiers audio pour les faire transcrire
- Formats supportés : WebM, MP3, WAV, OGG, M4A, FLAC
- Taille maximale : 25MB

### Chat vocal
- Envoyez un message audio et recevez une réponse textuelle
- L'IA transcrit votre audio et y répond

## 📝 Bonnes pratiques

### ✅ À faire
- Soyez poli et respectueux avec l'IA
- Posez des questions claires et précises
- Utilisez l'IA pour apprendre et vous améliorer
- Partagez les informations utiles avec les autres joueurs

### ❌ À éviter
- Ne spammez pas le trigger
- Ne posez pas de questions inappropriées
- N'essayez pas de contourner les limites
- Ne demandez pas d'aide pour tricher ou exploiter des bugs

## 🔧 Si quelque chose ne fonctionne pas

### Problèmes courants
1. **L'IA ne répond pas**
   - Vérifiez que vous utilisez le bon trigger (`!ia`)
   - Attendez la fin du cooldown
   - Contactez un admin si le problème persiste

2. **Message de rate limit**
   - Attendez 1 minute avant de réessayer
   - Évitez d'envoyer plusieurs messages rapidement

3. **Réponse incohérente**
   - L'IA peut parfois faire des erreurs
   - Reformulez votre question
   - Vérifiez les informations avec d'autres sources
